# Research-on-Cross-Modal-Coverless-Steganography-Method-Based-on-Multi-modal-Keys-
This paper proposes cross-modal image-less steganography using DDIM inversion. Text is coded, embedded as strong signals into noise at key-driven positions, then a stego image is generated. Extraction recovers noise via inversion. Results: 100% extraction without attack, 96%/92% under JPEG (QF=80/60), 88%/80% under Gaussian noise.
